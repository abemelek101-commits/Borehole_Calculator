Formulae and notes

ΔE = E₂ − E₁; ΔN = N₂ − N₁; ΔZ = Z₂ − Z₁

Horizontal distance = √(ΔE² + ΔN²)

Azimuth = atan2(ΔE, ΔN), converted to degrees and normalized to 0–360°.

Inclination from horizontal = atan2(−ΔZ, horizontal distance). Positive inclination means downward; negative means upward.

3D straight-line length = √(ΔE² + ΔN² + ΔZ²).

Important: Z is assumed to be elevation, increasing upward. This calculates the straight line between two coordinate points, not a curved measured borehole trajectory. The result is grid azimuth; apply a grid-to-true-north correction if needed. If the points are identical, direction is undefined.
