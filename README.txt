BOREHOLE AZIMUTH & INCLINATION CALCULATOR

QUICK USE (no installation needed):
1. Copy Borehole_Azimuth_Inclination_Calculator.html to your Android phone or computer.
2. Open the file using Chrome or another modern browser.
3. It works offline and calculates locally; your coordinates are not uploaded.

INSTALL AS A HOME-SCREEN APP (Android):
The included index.html, manifest.webmanifest, sw.js and icons form an installable web app (PWA).
For Chrome to offer Install app / Add to Home screen reliably, publish these files to a static HTTPS website.
Then open that HTTPS address in Chrome and choose the browser menu > Install app (or Add to Home screen).
Opening a local HTML file alone generally cannot register a full PWA.

CALCULATION NOTES:
- Elevation Z is assumed to increase upward.
- Azimuth is clockwise from grid north.
- Inclination convention can be changed between horizontal and vertical.
- Results are straight-line endpoint calculations, not a curved downhole survey.
